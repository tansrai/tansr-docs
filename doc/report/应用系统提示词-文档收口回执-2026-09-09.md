## 本轮发现并关闭的问题

**DOC-GEN-01：新增 SDK 导出后首次生成的覆盖率遗漏新页面。** `generateAll` 先在内存中收集页面，末位 coverage 仍扫描旧磁盘，随后才统一写盘；生成器顺序虽然正确，覆盖率实际读取时间早于新文件落盘。新增导出会出现 `gen:check` 单独报覆盖率差异，必须再生成一次。

修复保持总入口的纯内存生成方式，由 coverage 叠加本轮已生成的页面清单与正文。新页、更新的标题和日期立即参与统计；非文章产物不计入，生成过程不额外修改磁盘。增加内存叠加回归测试和“空内容目录首次全量生成 → 写盘后 coverage 逐字节相同”的集成验证，避免依赖手工二次生成。

**DOC-OPS-01：发布保留份数说明与实际策略不一致。** 对照 `J:/tansr/deploy/scripts/docs-switch.sh` 的 `KEEP` 默认值 3，将本仓 README 与 publish.sh 注释、日志的“5 份”改为“3 份”。只同步说明，未修改远端或本地保留策略。原有历史验收报告保留当时记录，本回执作为现行更正；根代理已将部署仓 README 同步并提交 `53a6d18d0ce3e7696ab836a141c17005a8872920`。
