연락하기 전에 1분만 [도움말 센터](/ko/support/)의 그룹별 문답과 [문제 해결 가이드](/ko/support/troubleshooting/)를 살펴보세요. 대부분의 문제는 거기에서 해결됩니다. 정말 사람이 봐야 한다면 아래 진입점 중 하나를 이용하세요.

## 진입점 1: WeChat

![WeChat 지원 QR 코드(업로드 예정)](/wechat-support.png)

**QR 코드는 업로드 예정입니다.** 위 이미지는 현재 자리 표시 이미지이며, 정식 QR 코드가 준비되면 교체합니다. 그 전까지는 아래 이메일 진입점을 이용해 주세요.

스캔해서 그룹에 들어간 뒤에는 문제 설명을 그룹에 바로 보내세요(아래 "네 가지를 명확히 쓰기" 참고). 먼저 인사하고 답을 기다릴 필요가 없습니다.

## 진입점 2: 이메일

[support@tansr.com](mailto:support@tansr.com)

이메일 제목은 "[형태] 한 문장 문제"로 쓰는 것을 권합니다. 예: "[CLI] tansr init에서 PAT가 유효하지 않다고 표시됨" 또는 "[세션 서비스] resume이 항상 409". 근무 시간 안에 가능한 한 빨리 답변합니다. 근무 시간 외의 이메일은 받은 순서대로 처리합니다.

이메일 클라이언트를 열고 싶지 않으면 아래에 바로 작성해도 됩니다. 폼도 마찬가지로 이메일 형태로 지원 메일함에 전달되며, 제출에 성공하면 티켓 ID를 드립니다. 당장 제출할 수 없으면 페이지가 제목과 설명이 채워진 이메일 링크를 제공합니다.

## 어느 진입점이 더 적합한가

| 상황 | 권장 |
|---|---|
| 한 문장으로 설명할 수 있고, "내가 잘못 쓴 건가"를 빨리 확인하고 싶음 | WeChat 그룹 |
| 진단 출력, 로그, 트랜스크립트 등 긴 자료를 첨부해야 함 | 이메일 |
| 과금, 인보이스, 계정 소속 등 신원 확인이 필요한 일 | 이메일. 등록된 이메일 주소로 보내 주세요 |
| 보안 취약점 | 이메일. 제목을 "[보안]"으로 시작하고, 그룹에 보내지 말 것 |
| 문서 오류나 누락 | 이메일. 페이지 주소를 명시 |

같은 문제는 진입점 하나만 이용해 주세요. 양쪽에서 중복 처리하는 것을 피하기 위해서입니다.

## 네 가지를 명확히 쓰기

이 네 가지를 함께 보내 주시면 대부분의 문제는 한 번에 짚어 낼 수 있습니다.

1. **어떤 형태를, 어떤 버전으로 쓰고 있는가.** CLI는 `tansr --version` 실행. SDK / 세션 서비스는 `package.json`의 `@tansr/sdk` / `@tansr/serve` 버전 확인. 모바일은 SDK 좌표 버전과 시스템 버전을 기재.
2. **진단 출력.** CLI는 `tansr doctor --json`을 붙여 넣기(키 값은 포함하지 않으며, 자격 증명은 지문 형태로만 나타남). 세션 서비스는 `GET /readyz` 응답과 관련 구조화 로그 줄을 붙여 넣기.
3. **오류 코드와 완전한 메시지.** 예: `429 plan_concurrency_exceeded`, `409 resume_unavailable`. 세션 서비스 쪽은 응답 헤더 `x-request-id`도 첨부. 모바일은 `connectionState`의 변화 순서를 첨부.
4. **재현 단계와 시각.** 과금과 관련되면 주문 번호 또는 청구 월, 그리고 계정 지문(`tansr init` 요약 카드에 표시되는 형태).

대화 내용을 보여 주어야 할 때는 `tansr sessions export <id>`로 트랜스크립트를 내보내세요. 키는 이미 자동으로 `sk-...뒤 4자리` 형태로 마스킹되어 있으므로 바로 첨부할 수 있습니다.

## 보내지 말아야 할 것

- **어떤 키 값도**: 개인 액세스 토큰, 앱 키 appkey, 모델 공급자 API key, 세션 서비스 Bearer. 이것들 없이도 문제를 해결할 수 있습니다. 실수로 보냈다면 즉시 콘솔에서 교체하세요.
- `.env` 파일 내용.
- 실제 고객 데이터가 담긴 전체 로그. 마스킹하거나 관련 줄만 잘라 주세요.

## 답변을 받은 뒤

- `tansr doctor --json`이나 어느 엔드포인트의 응답을 한 번 더 요청할 수 있습니다. 연관을 위해 같은 이메일 / 같은 그룹 메시지 스레드에서 답해 주세요.
- 문제가 결함으로 확인되면 수정이 어느 버전에 포함될 예정인지 알려 드립니다. 버전이 릴리스되면 [릴리스 노트](/releases/cli)(CLI), [SDK 릴리스 노트](/releases/sdk), [세션 서비스 릴리스 노트](/releases/serve)에서 확인할 수 있습니다.
- 문제가 해결되면 편하실 때 "해결됨"이라고 한마디 답해 주세요. 그것을 근거로 후속 조치를 종료합니다.

## 보안 문제

발견한 것이 보안 취약점(자격 증명 유출 경로, 권한 상승, 주입 면)이라면 그룹에 **보내지 말고**, [support@tansr.com](mailto:support@tansr.com)으로 직접 이메일을 보내고 제목을 "[보안]"으로 시작하세요. 우선적으로 처리하며 수정 전까지 소통을 유지합니다.

## 문서 피드백

각 문서 하단에 "이 페이지가 도움이 되었나요"가 있습니다. 문서의 오류나 누락도 페이지 주소와 문제 위치를 이메일로 직접 알려 주시면 환영합니다.
